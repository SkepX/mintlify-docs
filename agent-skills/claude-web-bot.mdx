# Trade in 2 Minutes with Any AI

You do not need to write code or set up any infrastructure. Copy the Ascend skill reference into Claude.ai, ChatGPT, or any AI assistant and you have a working trading bot in under two minutes.

---

## Step 1 - Copy the Skill

Go to the [Skill Reference](./skill-reference) page and copy the entire markdown block. It contains everything the AI needs: endpoints, auth, workflows, and safety rules.

## Step 2 - Open Claude or any AI

Open [claude.ai](https://claude.ai) or any AI assistant. Start a new conversation and paste the skill as your first message with this prefix:

```
Use the following skill to help me trade on Ascend.
My API key is: <your-api-key>
My wallet address is: <your-address>

[paste skill here]
```

## Step 3 - Start Trading

That is it. Now just talk to it:

```
What markets are live right now?
```

```
Show me the orderbook for BTC 100k.
```

```
Go YES on BTC 100k, 10 USDC margin, 2x leverage. Check my balance first.
```

The AI will run pre-trade checks, show you a summary, and wait for your confirmation before placing the order.

---

<Note>
  Keep your API key in a private conversation. Do not share the chat or use shared workspaces.
</Note>
